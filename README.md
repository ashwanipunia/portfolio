## Adding a Favicon to the Website

The website is already configured in `index.html` to display a custom favicon named `favicon.png`.

### HTML Code Added
The following `<link>` tags have been included inside the `<head>` section of `index.html`:

```html
<!-- Favicon -->
<link rel="icon" type="image/png" href="favicon.png">
<link rel="apple-touch-icon" href="favicon.png">
```

### Steps to Complete Setup
1. Save your favicon image as **`favicon.png`** (preferably a square PNG image, e.g., 32x32, 64x64, or 180x180 pixels).
2. Place `favicon.png` in the root directory of this repository (the same folder where `index.html` is located).
3. Open or refresh `index.html` in your web browser. The favicon will automatically display on browser tabs and bookmarks.
